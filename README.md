# 🔢 Counter App

A simple, clean counter app built for Android — tap to increment, tap to reset. Built as a hands-on exercise in native Android development with Kotlin.

![Platform](https://img.shields.io/badge/platform-Android-3DDC84?logo=android&logoColor=white)
![Language](https://img.shields.io/badge/language-Kotlin-7F52FF?logo=kotlin&logoColor=white)
![UI](https://img.shields.io/badge/UI-XML%20%2F%20ConstraintLayout-blue)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

---

## ✨ Features

- ➕ **Increment** — tap to increase the count
- 🔄 **Reset** — instantly bring the count back to zero
- 🎨 Clean, minimal Material Design UI
- 📱 Built with **View Binding** for safe, type-checked view access
- 🔁 Survives screen rotation without losing your count

---

## 🛠️ Built With

- **Kotlin** — 100% Kotlin, no Java
- **XML + ConstraintLayout** — native Android views, no Compose
- **View Binding** — type-safe view references
- **Material Components** — for button styling

---

## 🚀 Getting Started

### Prerequisites

- Android Studio (latest stable)
- An Android device or emulator running API 23+

### Installation

```bash
git clone https://github.com/pabloesc1999/counter-app.git
```

Open the project in Android Studio, let Gradle sync, then run it on your device or emulator.
